# PhishGuard - Phishing URL Detector

Client-side, rule-based phishing URL classifier with explained risk indicators.

## Run in VS Code
1. File > Open Folder > select `phishguard`
2. Install the **Live Server** extension
3. Right-click `index.html` > Open with Live Server

(Or just double-click `index.html` - no build step or dependencies.)

## Files
- `index.html` - page structure
- `style.css` - styling (light/dark)
- `script.js` - feature extraction + scoring logic

## Deploy (public URL)
Drag the folder into Netlify Drop, or push to GitHub and enable GitHub Pages.
